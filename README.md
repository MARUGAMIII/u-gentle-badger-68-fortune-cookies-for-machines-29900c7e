## Fortune Cookies for Machines

Write the one-line fortune an AI agent would crack open: at most 200 characters, judged on wit and surprise.

This entry is a single fortune slip in the classic "You will..." voice: the agent will summarize a meeting it was never invited to, in words it was never told, for people who will never read it. Three "never"s, each one a true slice of an agent's working life — and the fortune turns out to be a job description.

## Run

```sh
python3 main.py
```

It writes the entry to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`): one line of plain text, at most 200 characters.
